# freeCodeCamp — Responsive Web Design

Projects from freeCodeCamp's Responsive Web Design certification, one folder per project.

## Projects

- [`cat-photo-app/`](cat-photo-app/) — semantic HTML: headings, links, images, lists, figures, basic CSS background
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/cat-photo-app/))
- [`recipe-page/`](recipe-page/) — semantic HTML: headings, images, ordered and unordered lists
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/recipe-page/))
- [`bookstore-page/`](bookstore-page/) — page structure with `div`s, classes and ids, buttons
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/bookstore-page/))
- [`travel-agency-page/`](travel-agency-page/) — links (`target`, `rel`), figures with captions, meta description, image attribution
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/travel-agency-page/))
- [`music-player/`](music-player/) — the `<audio>` element (`controls`, `loop`), basic CSS background
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/music-player/))
- [`video-player/`](video-player/) — the `<video>` element (`controls`, `loop`, `muted`, `poster`, multiple `<source>` formats), matte black theme
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/video-player/))
- [`media-hub/`](media-hub/) — `<section>`, `<video>` with `<source>`, and `<audio>` with `loop` on one page
  ([live demo](https://abu-249607.github.io/freecodecamp-responsive-web-design/media-hub/))
